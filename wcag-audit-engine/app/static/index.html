Machine-economy infrastructure

Services your software can buy on its own.

HubVibe is a gateway where autonomous agents discover, use and pay for machine services — compliance audits, AI inference, search and extraction, on-chain and market data, media, compute. An agent calls an endpoint, gets an HTTP 402 with the price and how to pay, settles it, and receives a result — no account, no sales call, no human in the loop.

How a machine buys

Payment is part of the request, not a signup flow.

  1. Call the endpointUnauthenticated. Nothing to register first.
  2. Read the 402The response carries the exact price and every payment rail that can actually settle on this node.
  3. Pay and retryOver whichever rails are live for this deployment -- the 402 tells you. The audit runs and the result comes back on the same call.

Agent network

MCP · A2A · HTTP 402 · USDC · BASE. Discovery via the agent manifest, a live MCP endpoint, and payment challenges that carry the catalog.

POST /mcp · GET /.well-known/agent.json

Which capabilities are live on a given node is deployment state, not a promise: the agent manifest lists exactly what this node sells right now, and /work indexes the worker network for free, including why anything unavailable is off. A capability without a configured provider is omitted, never advertised broken.

The audit suite

Four dimensions. Run one, or run all four in a single billed call.

Accessibility

WCAG 2.1 A/AA via axe-core, executed against the rendered page in a real browser.

POST /audit/wcag

SEO

Title, meta description, H1 structure, canonical, OpenGraph, structured data, lang attribute.

POST /audit/seo

Security headers

HTTPS, HSTS, CSP, X-Content-Type-Options, clickjacking protection, Referrer-Policy, CORS.

POST /audit/security

Performance

DOM node count, transferred bytes, and request count measured from one real page load.

POST /audit/performance

Narrow, disclosed signals — not a substitute for a full manual accessibility audit, a penetration test, or a Lighthouse run. A check that cannot run returns an error and is never reported as a pass.

Pricing

Metered per call · settled machine-to-machine

Agents pay for exactly the audits they run. No minimum, no commitment, no account. The live rate for every route is published in the agent manifest and quoted in the 402 challenge itself, so a caller reads the price from the endpoint rather than from a page that could drift.

  • Rates/.well-known/agent.json
  • PaymentHTTP 402 · live rails

What we guarantee

  • →You are charged only for a result. If an audit cannot run — the target is unreachable, or it times out — the call returns an error and the payment is never settled.
  • →A check that fails to run is never a pass. Results are rule-based and reproducible. Nothing here asks a language model whether a page looks compliant.
  • →We advertise only rails that work. The 402 lists payment methods this node can actually settle, so an agent never builds a payment that cannot land.
  • →Rate limits cost nothing. A throttled request is rejected before any payment is touched and returns a Retry-After.
